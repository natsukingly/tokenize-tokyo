# TOKENIZE TOKYO visual variants

**Cyberpunk** is the default theme. **Original** remains available as an alternate skin. Cyberpunk is inspired by the yellow-and-black identity of Cyberpunk: Edgerunners, restrained to charcoal surfaces, off-white text and one yellow accent. Yellow identifies primary actions, selections and highlighted spaces; there are no large yellow backgrounds, cyan/magenta decoration or RGB shadows. The logo is a custom brush wordmark in white with a small yellow slash. Asset categories remain distinguishable by their icons and labels; red is reserved for errors.

- Main UI: `http://127.0.0.1:3000/` (Cyberpunk). Explicit previews: `?theme=cyberpunk` or `?theme=original`.
- The header has no theme switch. The Original design remains available only through `?theme=original` for development comparisons. Normal visits always use Cyberpunk, including browsers with an older saved theme preference.
- **Tokenize** opens a modal over the current screen. The map, filters and draft step remain in place. Escape, the close button or the backdrop dismiss it; reopening resumes the draft during the current visit. Location selection, the demo actor selector and owner tutorial work inside the same modal. **View listing** closes it and opens the new right on the map.
- Opening a theme preview reloads the page and preserves saved demo holdings and market sandbox data. It does not change `demo` / `multibaas` mode or submit transactions.
- Cyberpunk Explore opens in **Map first**: the map fills the available viewport, with the brush wordmark at the top of the expanded sidebar. Collapsing it leaves a compact T/arrow mark above the icon rail. The desktop header keeps a global **Tokenize** action; phones retain the header wordmark, a compact + action and bottom navigation. Compact **Filters** and **Map tools** controls expand on demand. Large promotional headings are removed from every page. The small **About this map** information control contains the demo/data explanation; provider attribution remains visible. Click a space or **View right** to open the details and purchase panel; its header lists the space type and area horizontally. The sidebar **Dashboard** opens the metrics and analysis; there is no Overview header button. Layout and sidebar choices last for the current visit and never reset market data.
- **Assets** is a separate directory, available from the sidebar in both themes. Name/district search, type/state filters and offer-price sorting sit above a compact table; smaller screens use cards. Its filters are independent of the map and survive navigation. **View on map** clears incompatible map filters and opens the selected asset's terms/purchase panel. No asset-card list remains on the homepage.
- **Quick tour** is an English floating coachmark, with a highlighted target and directional arrow. It keeps the map visible and works inside the tokenization dialog. Map tiles remain an external dependency; **Assets** works without them, and the details/purchase panel remains available if tiles fail.

- **Activity** shows 20 events per page, with Previous / Next and Latest controls. An older page remains anchored when new events arrive.
- **Markets** uses location-specific 3D map thumbnails, with a yellow point and category badge. External tiles are captured once into a session-cached image and the renderer is released. Attribution remains below the list; fictional demo locations stay labeled. The market explanation is expandable.

The existing green logo is retained in `Dashboard.tsx`. The active Cyberpunk logo is [cyberpunk-brush.png](../public/brand/cyberpunk-brush.png), a 2098 × 749 transparent PNG generated with the built-in imagegen tool. See the [exact generation prompt](BRAND_ASSET_PROMPT.md). The geometric [mark](../public/brand/cyberpunk-mark.svg) is used only for the collapsed sidebar. The earlier [wordmark](../public/brand/cyberpunk-logo.svg) remains an unused SVG draft.

Colors are isolated in `src/app/cyberpunk.css` under `[data-theme="cyberpunk"]`; `src/app/city-view.css` scopes the optional layout to `.city-view`. `use-theme.ts` defaults to Cyberpunk and handles explicit preview URLs. `TokyoMap.tsx` switches colors and observes container resizing so layout changes keep the same map instance. There is no flashing or strobing animation in the logo.

Verification: `npx playwright test tests/theme.spec.ts tests/tokenize-modal.spec.ts --workers=1` checks previewing both themes after a purchase, map area and canvas preservation on layout changes, restoration of the original logo, unchanged protocol data, mobile details/filter interaction without horizontal overflow, the default theme, modal focus containment, draft/map preservation, backdrop/Escape dismissal, and the owner tutorial inside the mobile modal.

The pitch deck keeps its original green styling. The new app theme is available for comparison without changing the presentation's visual direction.
